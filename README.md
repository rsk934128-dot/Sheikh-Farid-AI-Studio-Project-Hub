## 📌 পরিচিতি (Overview)
**Sheikh Farid AI Studio & Project Hub** হলো একটি সর্বাধুনিক ফুলস্ট্যাক প্রগ্রেসিভ ওয়েব অ্যাপ (PWA), যা বাংলা ভাষাভাষী নাগরিক, শিক্ষার্থী ও ডেভেলপারদের জন্য একক প্ল্যাটফর্মে শক্তিশালী টুলস সরবরাহ করে। একে **'মিনি মাইক্রোসফট'** হিসেবে ডিজাইন করা হয়েছে, যার মধ্যে রয়েছে হাই-প্রিসিশন বাংলা এআই ইঞ্জিন, ডিজিটাল বাংলাদেশ সিটিজেনডেস্ক (অনলাইন জিডি ও আবেদনপত্র প্রস্তুতকারক), সরাসরি জিমেইল এপিআই ইন্টিগ্রেশন এবং সফটওয়্যার আর্কিটেক্ট শেখ ফরিদের বিভিন্ন উদ্ভাবনী প্রকল্পের হাব।

## 🚀 প্রধান ফিচারসমূহ (Key Features)

### ১. 🧠 বাংলা হাই-প্রিসিশন এআই ল্যাব (AI Lab)
* **Gemini 2.5 Flash ইন্টিগ্রেশন:** দ্রুতগতির সর্বাধুনিক এআই মডেলের সাথে সরাসরি সংযোগ।
* **জিরো-ল্যাটেন্সি ক্লায়েন্ট ক্যাশ:** সাধারণ প্রশাসনিক প্রশ্নের উত্তর ও আইনি ড্রাফটের জন্য এজ ক্যাশিং, যা 0ms ল্যাটেন্সিতে তাৎক্ষণিক উত্তর দিতে সক্ষম।
* **স্মার্ট প্রম্পট চিপস:** অনলাইন জিডি খসড়া, প্রশাসনিক ছুটির আবেদন, কোড রিভিউ ও এপিআই স্ক্রিপ্ট জেনারেশন।

### ২. 🏛️ সার্ভিস সরকার (CitizenDesk BD)
* **অনলাইন জিডি (GD) জেনারেটর:** থানা ও জেলা সিলেক্ট করে হারানো জাতীয় পরিচয়পত্র, ড্রাইভিং লাইসেন্স বা মোবাইল ফোনের জন্য মানসম্মত ফরম্যাটে তাৎক্ষণিক জিডি ড্রাফট।
* **প্রশাসনিক আবেদনপত্র জেনারেটর:** সরকারি ও বেসরকারি চাকুরিজীবীদের জন্য অফিসিয়াল ছুটির আবেদনপত্র স্বয়ংক্রিয়ভাবে তৈরি করার সুবিধা।
* **জরুরি জাতীয় হটলাইন ডিরেক্টরি:** ৯৯৯ (জরুরি সেবা), ৩৩৩ (নাগরিক তথ্য), ১০৯ (নারী ও শিশু সুরক্ষা), ১০৬ (দুদক), ১৬১২২ (ভূমি সেবা) নম্বরে সরাসরি ডায়াল করার সুবিধা।
* **লাইভ অফিসিয়াল প্রিভিউ ও প্রিন্ট:** সরাসরি প্রিন্ট ও কপি করার ওয়ান-ক্লিক অপশন।

### ৩. ✉️ জিমেইল ওয়ার্কস্পেস ও লেবেল ফিল্টারিং (Gmail API Workspace)
* **রিয়েল-টাইম লেবেল ফেচিং:** Google REST API (`/users/me/labels`) এর মাধ্যমে ইউজারের সমস্ত ইনবক্স, স্টারড, ইমপর্ট্যান্ট ও কাস্টম লেবেল তালিকা প্রদর্শন।
* **সাইডবার ফিল্টার মেনু:** সাইডবার থেকে যেকোনো লেবেলে ক্লিক করে তৎক্ষণাৎ সংশ্লিষ্ট ইমেইল মেসেজগুলো ফিল্টার ও ব্রাউজ করা।
* **নিরাপদ Google OAuth 2.0:** ক্লায়েন্ট-সাইড Bearer টোকেনের মাধ্যমে নিরাপদ ডাটা রিট্রিভাল।
* **ডেমো মোড সাপোর্ট:** ইন্টারনেট বা এক্সেস টোকেন ছাড়াও ইন্টারফেস টেস্ট করার চমৎকার ডেমো মোড।

### ৪. 🚀 শেখ ফরিদ প্রজেক্ট হাব (Projects Hub)
* **ScrollVerse (স্ক্রোলভার্স):** ফিউচারিস্টিক ইনফিনিট ক্যানভাস ও মাল্টিটাস্কিং ইন্টারফেস।
* **CitizenDesk BD:** বাংলাদেশ পাবলিক সার্ভিস পোর্টাল।
* **NoorAI & FastGov Edge:** আল্ট্রাফাস্ট বাংলা এআই মডেল।
* **Sheikh Code Exchange:** ডেভেলপার ইউটিলিটি ও কোড সিনট্যাক্স অপ্টিমাইজার।
* **Mini Microsoft Suite:** অল-ইন-ওয়ান পিডব্লিউএ প্রোডাক্টিভিটি স্যুট।

### ৫. 📱 PWABuilder ১০০/১০০ কমপ্লায়েন্ট (PWA Engine)
* **মাইক্রোসফট PWABuilder অডিটে ১০০/১০০ স্কোর:** আধুনিক সার্ভিস ওয়ার্কার (Service Worker with Workbox) এবং ওয়েব অ্যাপ ম্যানিফেস্ট।
* **অফলাইন সাপোর্ট:** কোনো ইন্টারনেট সংযোগ না থাকলেও ক্যাশড ইন্টারফেস ও লোকাল টেমপ্লেট নিরবচ্ছিন্নভাবে ব্যবহার করা যায়।
* **ইনস্টলেশন ব্যানার:** অ্যান্ড্রয়েড, উইন্ডোজ, ম্যাক ও আইওএস এ নেটিভ অ্যাপের মতো ইনস্টল করার অপশন।

## 🛠️ টেক স্ট্যাক (Tech Stack)

| কম্পোনেন্ট | প্রযুক্তি |
|---|---|
| ফ্রন্টএন্ড কোর | React 19, TypeScript 5.7 |
| স্টাইলিং ও ডিজাইন | Tailwind CSS v4.0 (আধুনিক গ্লাস ও ডার্ক থিম) |
| বিল্ড টুল ও বান্ডলার | Vite 6 |
| পিডব্লিউএ ইঞ্জিন | Vite Plugin PWA, Workbox Window |
| এআই কোর | Google GenAI SDK (`@google/genai`) |
| ওয়ার্কস্পেস সংযোগ | Google Workspace Gmail REST API v1 |
| অথেনটিকেশন | Firebase Auth 13 (পপআপ ক্লোজ হ্যান্ডলিং সহ) |
| আইকন সেট | Lucide React |
